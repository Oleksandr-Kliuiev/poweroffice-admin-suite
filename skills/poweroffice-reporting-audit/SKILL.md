# PowerOffice Reports and Delivery

Read the [Chrome contract](../poweroffice-admin-suite/references/browser-operation-contract.md) if absent from working context; retain it across related commands. Load only the relevant workflow section below, including its prerequisites and verification.

- Show/export/email: read [report delivery](references/report-delivery.md). Export from PowerOffice and send through Outlook on the web in the same authenticated Chrome profile on Windows or macOS. An explicit typed or spoken request authorizes that exact report email once scope and recipient are grounded.
- Reconcile/investigate/audit: read the relevant [reporting and audit](references/reporting-audit.md) section. Keep records read-only unless a correction is separately requested.

Verify report type, period/as-of date, company versus customer scope, filters, currency and posted/draft basis where relevant. Reuse explicit instructions or the clearly selected view; never guess missing scope or turn simple delivery into reconciliation.

Report company/customer, report/period, recipient and observed export/Outlook Sent Items status; claim inbox delivery only with independent confirmation.
