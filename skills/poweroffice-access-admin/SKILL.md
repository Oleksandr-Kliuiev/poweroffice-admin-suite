# PowerOffice Access Admin

Read the [Chrome contract](../poweroffice-admin-suite/references/browser-operation-contract.md) if absent from working context; retain it across related commands. Load only the relevant workflow section below, including its prerequisites and verification.

Use [access operations](references/access-operations.md): read **Role model** before any role assignment/change, then **Invite or assign** or **Deactivate or remove access** as needed. Inspect role privileges; search inactive users and pending invitations by exact email.

A user and employee record are distinct until linked. Use least privilege and an approved catalog profile when available; never copy privileged access from a similarly titled peer. Check protected ownership (including security contact/subscription administrator), approval chains and visible sessions before removal. Preserve employee/accounting history.

Report the exact email, role change, invitation/access state, affected privileged capabilities and outstanding responsibilities or human steps.
