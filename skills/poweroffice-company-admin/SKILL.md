# PowerOffice Company Admin

Read the [Chrome contract](../poweroffice-admin-suite/references/browser-operation-contract.md) if absent from working context; retain it across related commands. Load only the relevant workflow section below, including its prerequisites and verification.

Read the requested setting under [Dependency-aware changes](references/company-settings.md#dependency-aware-changes), with context and verification sections as needed. Inspect current values and dependent modules first.

Use an existing catalog only for the selected company's intended defaults; verify live values. Paid subscription activation, historical numbering, bank details, VAT registration and accounting defaults affecting future postings need explicit authorization for that exact change and its impact. Never infer legal/tax settings from another company.

Report setting before/after, effective scope, dependencies and future-only behavior where applicable.
